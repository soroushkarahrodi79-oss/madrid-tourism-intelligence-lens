# Institutional Decision Journey V1

## Case and professional question

The bounded case starts at a real point inside **APE.02.20 CÁRCEL DE YESERÍAS**
in Arganzuela and asks:

> What do official planning and administrative records document here, and how
> does that documented situation differ from nearby APE.02.12 C/ BOLÍVAR Y C/
> COBRE?

The pair is methodologically useful because both are official residential
planning ámbitos in the same district, both have current published development
state and available-buildability evidence, both are read from the same named
source editions, and the existing ámbito-comparison contract accepts their
like-for-like fields. Their published surfaces are similar but are not treated as
identical. The case does not compare a Lens-circle count with an ámbito quantity.

The primary location is `40.395543, -3.691757`, inside APE.02.20, with a 900 m
Lens radius. In the committed granted-licence artifact, the existing default
date window yields resolved address-point records inside that circle. The live
application computes and displays their family-specific counts; the journey
does not duplicate or hard-code them.

## Journey

1. **PLACE** restores the real coordinate and distinguishes the Lens circle,
   whole barrio and whole planning ámbito.
2. **Official evidence** keeps the existing four independent phase readings,
   available buildability, source dates and granted-licence family counts.
3. **COMPARE** selects APE.02.20 and APE.02.12 in the existing official-geometry
   comparison. Same/different categorical readings and numeric `B − A` values
   come only from the existing comparison model; incompatible values remain
   withheld with reasons.
4. **EVIDENCE** opens the existing Evidence & limits drawer, including source,
   scope, freshness, interpretation ceiling, versioned share URL and export.

The journey is an inline aid in the existing analysis panel. It adds no map
control, data source, derived metric or analytical model. Exiting returns to
PLACE, restores the Lens comparison scope and disables the licence layer only
when the journey itself enabled it.

## What this case does not establish

- It does not establish construction start, completion, occupancy or physical
  change. A granted licence is an administrative grant, not a built outcome.
- It does not combine the four planning phase fields into a stage, percentage,
  timeline or progress score.
- It does not turn available buildability into a dwelling count or a forecast.
- It does not apportion whole-ámbito or whole-barrio quantities to the Lens
  circle.
- It does not establish causality, desirability, priority, impact, tourist
  pressure, saturation, carrying capacity, ranking or a recommended decision.
- It does not reopen the held INE experimental tourist-dwelling research.
