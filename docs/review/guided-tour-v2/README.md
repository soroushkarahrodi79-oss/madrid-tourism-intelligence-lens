# Guided Tour V2 visual review

These captures were produced by `browser-tests/tutorial.browser.mjs` with the
repository's local static server and headless Chromium.

- `before/` serves the verified baseline `0e8b3a77112cb64376019c29aa4d00f284412b85`.
- `after/` serves Guided Tour V2 from the feature worktree.
- Desktop, 390 × 844 phone and 834 × 1112 tablet layouts are represented.

The after set records the new M1, M2, M3 and K11/K13 instruction steps. M2 and
M3 screenshots intentionally show the honest fallback state: no question is run
and no dossier action is fabricated for the capture.

These are browser-engine screenshots at emulated viewports, not physical-device
or screen-reader evidence.
