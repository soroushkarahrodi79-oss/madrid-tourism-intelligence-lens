# UX-O1 tutorial visual proof

These screenshots are captured by `browser-tests/tutorial.browser.mjs` against
the real local application (`CAPTURE_TUTORIAL_SHOTS=1`), not mockups.

- `01-first-visit-desktop.png` — optional desktop invitation.
- `02-first-visit-mobile.png` — optional iPhone-size invitation.
- `03-place-radius-desktop.png` — PLACE/radius step.
- `04-layers-mobile.png` — mobile Layers step.
- `05-compare-mobile.png` — COMPARE step.
- `06-evidence-mobile.png` — Evidence & limits step and its safe offscreen fallback.
- `07-dark-mobile.png` — dark appearance guide.
- `08-spanish-mobile.png` — Spanish guide.

Usage: select **Guided tour** (or **Guía**) in the header at any time. The
guide only highlights current controls; it does not change a Lens, radius,
mode, basemap, layers, URL, or evidence state.
