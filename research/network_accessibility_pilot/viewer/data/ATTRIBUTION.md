# Attribution and licence notice — viewer build artifacts

Generated by `../build_viewer_data.py`. It covers **every file in this directory**,
and in particular `portal_coordinates.csv`, which cannot carry a notice inside
itself without breaking the parsers that read it. This mirrors the arrangement in
`../../results/ATTRIBUTION.md`, which covers `results/` and not this directory.

## What came from where

| File | Official sources | OpenStreetMap |
|---|---|---|
| `portal_coordinates.csv` | the whole file: `cod_ndp` and the `x_25830`/`y_25830` callejero coordinates, reprojected to EPSG:4326 | **nothing** |
| `study_barrio.geojson` | the whole file: one barrio polygon copied unmodified from `data/geography/madrid_admin.geojson` | **nothing** |
| `build_manifest.json` | record counts, bounds, transformation residuals, source checksums | the baseline figures it quotes from `pilot_report.json` are OSM-derived, and are reproduced there as expectations for the integrity check, not as new measurements |

**Neither derived data file carries a single OSM-derived value.** That is
deliberate. `portal_coordinates.csv` holds coordinates and nothing else, so no
ODbL-licensed measurement is redistributed by it. The viewer reads the
OSM-derived measurements directly from `../../results/origin_facility_distances.csv`,
whose own ODbL attribution and ODbL 4.6 statement remain the authoritative ones
in `../../results/ATTRIBUTION.md`.

## Why these files exist at all

Leaflet needs geographic coordinates, and the pilot publishes projected ones
(EPSG:25830). Rather than rewrite the pilot's table or republish it as a GeoJSON
carrying every distance attribute — which the pilot deliberately stopped doing,
see `exports.note` in `../../results/pilot_report.json` — the build step emits the
smallest possible join table and leaves the measurements where they were
published. The browser joins the two on `cod_ndp`.

## Reproducing them

```
cd research/network_accessibility_pilot/viewer
python build_viewer_data.py
```

The script is deterministic and fails closed: it aborts if a `cod_ndp` is
duplicated or empty, if any transformed coordinate falls outside a Madrid
envelope, if the pyproj round-trip residual exceeds 1 µm, if the 7-decimal
output quantisation exceeds 1 cm, or if `data/geography/madrid_admin.geojson`
does not contain exactly one barrio `113`. `build_manifest.json` records the
SHA-256 of all four inputs, so a drift in any of them is detectable.
