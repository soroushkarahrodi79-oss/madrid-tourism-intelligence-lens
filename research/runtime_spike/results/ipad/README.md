## Measurement caveats (do not overstate)

- **`interaction_to_paint_ms` is a double-rAF proxy**, frame-quantised, **not a true
  paint timestamp**; the synchronous analytical recompute is captured separately as
  `interaction_recompute_ms` (iPad full-recompute median 5–7 ms).
- **Readiness barriers are NOT equivalent between engines**: Leaflet adds layers
  synchronously and does **not** await raster basemap tiles; MapLibre awaits `idle` +
  `isSourceLoaded()` for every source. So `map_ready_ms`/FCP are **not** strictly
  engine-comparable; the interaction/pan metrics (identical scripted workload) are.
- **Cache/network**: `cold` cache, `wifi` only, a single session. No warm-cache or
  cellular figures.
- **Not full production Lens fidelity**: `recompute_fidelity` covers two production
  pure models (`licencesInLens` + `ambitosIntersecting`), **not** the full per-move
  Lens view update (panel/halo/evidence/area-profile/i18n), which is larger for both
  engines equally.
- Single physical device (iPad M3). A different iPad class (older A-series) is not
  covered and would scale lower.
